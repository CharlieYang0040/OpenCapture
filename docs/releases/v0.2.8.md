# OpenCapture v0.2.8 - Unified Capture and Modern Animation

OpenCapture v0.2.8은 캡처 대상을 모든 작업에서 공유하도록 화면 구조를 정리하고,
빠른 캡처·스크린샷·애니메이션 출력을 실제 사용 목적에 맞게 확장한 Windows x64
기술 프리뷰입니다.

## 주요 변경

- 창·모니터·영역 선택을 탭 밖의 공통 대상 바로 통합하고 중복된 대상 선택 UI를
  하나의 모달로 정리합니다.
- 캡처·비디오·애니메이션의 시작, 일시정지, 재개 및 중지를 같은 하단 세션 명령 바에
  배치합니다.
- `Ctrl+Shift+F8` 빠른 캡처는 임시 영역을 선택한 뒤 스크린샷·비디오·애니메이션 중
  실행할 작업을 고르게 합니다.
- 출력 경로를 파일 탐색기에서 바로 여는 버튼을 추가합니다.
- PNG 무손실, WebP 문서, WebP 균형, JPEG 호환 및 AVIF 최소 용량 스크린샷
  프리셋을 추가합니다.
- GIF 예상 용량 범위를 표시하고 Animated WebP와 Animated AVIF 출력을 추가합니다.
- 팝업과 탭에 번역과 무관한 고정 ID를 적용하고, 마우스 클릭 포커스 때문에 툴팁이
  남는 문제를 수정합니다.
- Animated WebP/AVIF에 필요한 libwebp, AOM, SVT-AV1 및 swscale 런타임과
  라이선스 자료를 배포 패키지에 포함합니다.

## 자동 및 실제 검증

- Visual Studio 2022 Build Tools, CMake, Ninja 및 pinned vcpkg 구성의 Release 빌드
- GitHub Actions와 같은 `vs2022-core-tests` 구성 및 Release CTest 각각 2/2 통과
- 1920x1080 MKV 입력을 Animated WebP 575프레임과 Animated AVIF 1,440프레임으로
  변환하고 서로 다른 표본 프레임 확인
- Animated AVIF의 23.983초 애니메이션 트랙과 1,439개 판독 프레임 확인
- HEVC 90프레임과 AAC 71프레임을 포함한 A/V mux smoke 통과
- PNG 스크린샷 smoke 통과
- 실제 1280x720 녹화 파일에서 WebP 59프레임/5.083초 및 AVIF 63프레임/5.25초,
  서로 다른 프레임 내용 확인
- Computer Use로 공통 대상 바, 출력 폴더 버튼, 캡처·비디오·애니메이션 탭과
  빠른 캡처 작업 선택 팝업 확인

## 알려진 경계

- Windows 탐색기 미리보기와 일부 사진 뷰어는 Animated WebP/AVIF의 대표 정지
  프레임만 표시할 수 있습니다. 파일의 애니메이션 프레임은 별도 디코드 검증했습니다.
- Animated AVIF는 지원하는 뷰어와 서비스가 Animated WebP/GIF보다 제한적입니다.
- Animated WebP에 대한 현재 FFprobe 판독은 `image data not found`를 보고할 수 있어,
  WebP 검증에는 RIFF 애니메이션 청크와 실제 다중 프레임 디코딩을 사용했습니다.
- 실제 게임 부하 비교, 장시간 A/V 드리프트, QSV/AMF와 다른 GPU·드라이버 조합은
  별도 수용 시험이 필요합니다.
- 실행 파일은 Authenticode 서명되지 않은 기술 프리뷰입니다.

## 설치

1. `OpenCapture-0.2.8-windows-x64.zip`과 `SHA256SUMS.txt`를 내려받습니다.
2. SHA-256을 확인하고 쓰기 가능한 폴더에 압축을 풉니다.
3. `OpenCapture.exe`를 실행합니다. 별도 설치 프로그램이나 관리자 권한은 필요하지 않습니다.
