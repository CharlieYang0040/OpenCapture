# OpenCapture v0.2.6 - Automatic Profile Codecs and Application Icon

OpenCapture v0.2.6은 목적형 녹화 프로필의 HEVC 강제를 제거하고 기존 Auto 코덱 정책을
사용하도록 전환하며, 새 OpenCapture 애플리케이션 아이콘을 적용한 Windows x64 기술
프리뷰입니다.

## 주요 변경

- `균형`, `용량 절약`, `품질 우선` 프로필이 HEVC를 직접 지정하지 않고 Auto 코덱을
  사용합니다.
- Auto 우선순위는 기존 결정대로 실제 D3D11 하드웨어 열기 결과를 반영한
  AV1 → HEVC → H.264 순서를 유지합니다.
- `게임 성능` 프로필은 낮은 부하와 넓은 재생 호환성을 위해 H.264를 유지합니다.
- 설정 스키마를 3으로 올려 이전 목적형 프로필에 저장된 HEVC 값을 Auto로 다시
  적용합니다. 직접 설정에서 선택한 코덱은 보존됩니다.
- 프로필 설명에서 고정 코덱 대신 Auto 선택임을 명확하게 표시합니다.
- 화면 캡처 프레임, 녹화 표시와 GPU 처리 흐름을 결합한 OpenCapture 아이콘을
  추가했습니다.
- 투명 원본 PNG와 16~256픽셀 다중 해상도 ICO를 저장소에 포함하고, 실행 파일,
  메인 창, 작업 표시줄과 알림 영역 아이콘에 연결했습니다.

## 자동 검증

- Visual Studio 2022, CMake, Ninja 및 pinned vcpkg 구성의 Debug/Release 빌드
- Debug/Release `opencapture_core_tests`, `opencapture_audio_tests` 각각 2/2 통과
- 목적형 프로필의 Auto 적용, schema 3 직렬화와 직접 설정 보존 단위 검증
- Release 실행 파일 FileVersion/ProductVersion 0.2.6 확인
- Release 실행 파일에서 32×32 연결 아이콘을 다시 추출하여 리소스 포함 확인
- PNG 투명 알파와 ICO의 16, 20, 24, 32, 40, 48, 64, 128, 256픽셀 항목 확인

## 알려진 경계

- Auto는 가장 최신 코덱을 우선합니다. 검증 PC의 RTX 3070 Ti에서는 AV1 D3D11 열기가
  실패하므로 HEVC가 선택될 가능성이 높으며, HEVC를 허용하지 않는 재생기나 업로드
  환경에서는 `직접 설정 → H.264`를 선택해야 합니다.
- MKV를 MP4로 copy/remux해도 영상 코덱은 바뀌지 않으므로 HEVC 파일이 H.264로
  변환되지는 않습니다.
- 실제 게임 FPS, 1% low와 GPU 부하 비교는 이번 수용 시험에 포함하지 않았습니다.
- 아이콘은 생성형 이미지 도구로 만든 원본을 프로젝트용 PNG/ICO로 변환했습니다.
- 실행 파일은 Authenticode 서명되지 않은 기술 프리뷰입니다.

## 설치

1. `OpenCapture-0.2.6-windows-x64.zip`과 `SHA256SUMS.txt`를 내려받습니다.
2. SHA-256을 확인하고 쓰기 가능한 폴더에 압축을 풉니다.
3. `OpenCapture.exe`를 실행합니다. 별도 설치 프로그램이나 관리자 권한은 필요하지 않습니다.
