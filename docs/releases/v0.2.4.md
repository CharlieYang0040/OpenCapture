# OpenCapture v0.2.4 - Compact Recording Profiles and Modern Codecs

OpenCapture v0.2.4는 녹화 파일 크기를 줄이기 위한 프로필, GPU 해상도 축소, 최신 코덱
선택과 고효율 NVENC 설정을 추가한 Windows x64 기술 프리뷰입니다.

## 주요 변경

- `Compatibility`, `Balanced`, `Compact`, `Custom` 녹화 프로필을 추가했습니다.
- `Compact`는 30fps, 최대 1080p, 고효율 인코딩과 최신 코덱 자동 선택을 기본으로 합니다.
- 일반 영상 녹화에서 원본, 최대 1080p, 최대 720p GPU 축소를 선택할 수 있습니다.
- H.264, HEVC, AV1 인코더 선택과 코덱별 폴백을 실제 녹화 경로에 연결했습니다.
- NVENC에 Realtime, Balanced, Efficient 모드를 추가했습니다. Efficient는 p5, VBR,
  B-frame, spatial/temporal AQ와 제한된 lookahead를 사용합니다.
- 해상도, FPS와 코덱을 반영한 자동 목표 비트레이트 및 1~100Mbps 사용자 지정 값을
  제공합니다.
- 설정 화면에 예상 시간당 용량을 표시하고, 녹화 중 실제 인코더, 출력 크기와 목표
  비트레이트를 표시합니다.
- MP4 copy가 재인코딩이나 용량 절감이 아니며 원본 MKV를 유지한다는 안내를 추가했습니다.
- 기존 v0.2.3 녹화 설정 파일은 Compatibility 기본값으로 계속 읽을 수 있습니다.

## 자동 검증

- Visual Studio 2022, CMake, Ninja 및 pinned vcpkg 구성의 Debug/Release 빌드
- Debug/Release `opencapture_core_tests`, `opencapture_audio_tests` 각각 2/2 통과
- NVIDIA H.264 NVENC, HEVC NVENC Efficient, OpenH264 각각 합성 10.026초
  600 영상 패킷 + AAC 470 패킷 MKV mux 검증
- Auto 모드에서 AV1 초기화 실패 후 HEVC 폴백과 120 영상 패킷 출력 검증
- 엄격 AV1 선택 시 초기화 실패 표면화, 호환 폴백 허용 시 HEVC 전환 검증
- HEVC/AAC MKV를 MP4로 무재인코딩 remux하고 600/470 패킷을 `ffprobe`로 검증
- 실제 앱 Video 탭에서 프로필 우선 배치, Compact 반영과 기본 설정 복원을 확인

## 알려진 경계

- 검증 PC의 NVIDIA GeForce RTX 3070 Ti는 AV1 인코더가 FFmpeg에 등록되고 장치가
  초기화되지만 실제 D3D11 인코더 열기는 `Function not implemented`로 실패했습니다.
  Auto는 HEVC로 안전하게 폴백하며, 명시적 AV1은 실패를 숨기지 않습니다.
- HEVC와 AV1 지원은 GPU 세대와 드라이버에 따라 달라집니다.
- Intel QSV, AMD AMF, AV1 지원 GPU, 실제 화면·게임 장시간 녹화, 4K→1080p 부하,
  장시간 A/V drift는 이번 자동 수용 시험에 포함하지 않았습니다.
- 실행 파일은 Authenticode 서명되지 않은 기술 프리뷰입니다.

## 설치

1. `OpenCapture-0.2.4-windows-x64.zip`과 `SHA256SUMS.txt`를 내려받습니다.
2. SHA-256을 확인하고 쓰기 가능한 폴더에 압축을 풉니다.
3. `OpenCapture.exe`를 실행합니다. 별도 설치 프로그램이나 관리자 권한은 필요하지 않습니다.
