# OpenCapture v0.2.0 - Quick Capture and Background Controls

OpenCapture v0.2.0은 반복 캡처 작업과 고해상도 모니터 사용성을 정리한 Windows x64
기술 프리뷰입니다. v0.1.1 이후 Quick Capture, 작업 중심 탭 UI, 캡처 단축키 출력 설정,
알림 영역 제어와 회사 PC에 적합한 기본 종료 정책을 추가했습니다.

## 주요 변경

- 현재 영구 대상과 Region 프리셋을 바꾸지 않는 `Ctrl+Shift+F8` Quick Capture
- 단축키 스크린샷 결과를 클립보드, PNG 또는 PNG+클립보드로 선택
- Region 선택 중 메인 창과 기존 대상 테두리를 숨겨 선택 영역을 가리지 않도록 개선
- Capture, Video, GIF, Settings 탭과 공통 대상·출력·Quick Capture 헤더
- 100~200% Windows DPI와 75~200% 사용자 보정을 결합한 적응형 UI
- 창 닫기 후 상주를 사용자가 직접 켜는 opt-in 알림 영역 모드
- 알림 영역의 앱 열기, Quick Capture, 현재 녹화 중지와 완전 종료 메뉴
- 신규 사용자에게는 창 닫기 시 완전히 종료되는 기본 정책
- 기능과 연결되지 않은 Cursor 설정을 비활성화하고 정확한 설명 제공

## 검증 기준

- CMake → vcpkg → Ninja → MSVC v143 → MSVC Linker Release 빌드
- Debug 및 Release CTest
- 합성 PNG·클립보드 스크린샷 스모크
- 기본 창 닫기 종료와 저장된 opt-in 트레이 상주 수명주기
- ZIP 압축 전후 모든 배포 파일 SHA-256 비교
- FFmpeg 대응 소스 안내, 실제 vcpkg 포트/패치와 링크된 빌드 설정을 별도 자산으로 제공
- 압축 해제한 배포본 프로세스 실행과 자동 스크린샷 스모크
- 사용자 환경에서 4K UI, Region 선택 창 숨김 및 Quick Capture 실기 확인

## 설치

1. `OpenCapture-0.2.0-windows-x64.zip`과 `SHA256SUMS.txt`를 내려받습니다.
2. ZIP의 SHA-256을 `SHA256SUMS.txt`와 비교합니다.
3. ZIP 전체를 한 폴더에 압축 해제합니다.
4. `OpenCapture.exe`를 실행합니다.

앱과 DLL, `licenses` 폴더를 ZIP 내부 구조 그대로 유지해야 합니다.

## 보안과 알려진 제한

- 이 프리릴리스 바이너리는 아직 Authenticode 코드 서명되지 않았습니다.
- Windows 서비스, 예약 작업, 시작 프로그램, 관리자 권한, 프로세스/DLL 주입 및
  게임 후킹을 사용하지 않습니다.
- 화면·오디오·클립보드 캡처는 회사 정책에 따라 서명과 별개로 사전 승인이 필요할 수 있습니다.
- Desktop Duplication 폴백, QSV/AMF 실기 검증과 장시간 성능 시험은 아직 완료되지 않았습니다.
- 현재보다 낮은 녹화 부하를 위한 변환 전 프레임 제한과 백그라운드 UI 중단은 조사만
  완료했으며 v0.2.0에는 포함하지 않았습니다.

This Windows x64 technical preview adds Quick Capture, configurable shortcut results, a task-based
tab UI, and opt-in notification-area background controls. The binary is currently unsigned.
