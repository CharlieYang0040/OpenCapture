# OpenCapture v0.2.3 - Minimized Window CPU Fix

OpenCapture v0.2.3은 메인 창을 최소화했을 때 UI 렌더 루프가 과도하게 반복되어 CPU를
사용하던 문제를 해결한 Windows x64 기술 프리뷰입니다.

## 주요 변경

- 최소화된 Win32 창이 `WS_VISIBLE`을 유지하는 특성을 고려해 `IsWindowVisible`뿐 아니라
  `IsIconic`으로 실제 상호작용 가능한 UI 상태를 구분합니다.
- DXGI가 가려진 스왑 체인의 VSync 대기를 건너뛰더라도 `Present`가 무제한 반복되지 않도록
  최소화 상태의 UI 업데이트를 10Hz로 제한합니다.
- 최소화 중에는 `MsgWaitForMultipleObjects`로 메시지 또는 다음 UI 주기를 기다리고,
  트레이로 숨긴 유휴 상태는 기존처럼 `WaitMessage`로 대기합니다.
- 최소화하거나 숨긴 상태에서 녹화할 때는 기존 100ms UI 주기를 유지하면서 캡처·인코딩
  파이프라인은 계속 처리합니다.

## 자동 검증

- Visual Studio 2022, CMake, Ninja 및 pinned vcpkg 구성의 Debug/Release 빌드
- Debug/Release `opencapture_core_tests`, `opencapture_audio_tests`
- 최소화 상태 5초 CPU 표본: 20 논리 프로세서 시스템에서 전체 CPU 약 0.016%
- NVENC 및 OpenH264 각각 합성 10.026초 H.264 600패킷 + AAC 470패킷 mux 검증
- 패키지 manifest, ZIP SHA-256 및 GitHub Release 재다운로드 검증

CPU 표본은 이번 검증 PC의 유휴 상태 측정값이며 모든 시스템의 절대 성능을 보장하지
않습니다. 실제 화면/게임 녹화, 장시간 A/V drift, GPU별 인코딩 및 다양한 Windows 창 상태는
수동 수용 기준으로 남습니다.

## 알려진 경계

- 하드웨어 인코딩 가용성은 GPU와 드라이버에 따라 달라집니다.
- 실행 파일은 Authenticode 서명되지 않은 기술 프리뷰입니다.

## 설치

1. `OpenCapture-0.2.3-windows-x64.zip`과 `SHA256SUMS.txt`를 내려받습니다.
2. SHA-256을 확인하고 쓰기 가능한 폴더에 압축을 풉니다.
3. `OpenCapture.exe`를 실행합니다. 별도 설치 프로그램이나 관리자 권한은 필요하지 않습니다.
