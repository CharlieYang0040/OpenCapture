# OpenCapture v0.2.2 - Custom Shortcuts and Persistent Recording Settings

OpenCapture v0.2.2는 전역 단축키를 키보드에서 직접 지정하고 비디오/GIF 설정을 재시작
후에도 유지할 수 있게 한 Windows x64 기술 프리뷰입니다.

## 주요 변경

- Settings의 `Set shortcut`에서 Ctrl, Alt 또는 Shift와 글자·숫자·기능 키·방향키 등의
  조합을 직접 입력할 수 있습니다.
- 단축키별 `Clear`와 `Restore Default`를 제공하고 앱 내부 중복이나 Windows/다른 앱의
  전역 단축키 충돌 시 기존 등록을 유지합니다.
- 입력 중에는 기존 전역 단축키를 잠시 해제하며 Esc 또는 포커스 상실로 안전하게
  취소할 수 있습니다.
- 비디오 FPS·품질·포맷·인코더·시스템 오디오·마이크와 GIF FPS·해상도·색상 수를
  `%LOCALAPPDATA%\OpenCapture\recording_settings.txt`에 원자적으로 저장합니다.
- Video와 GIF 탭에 개별 `Restore Default`를, Settings에는 단축키·녹화·GIF·스크린샷·
  UI 배율·테두리·영역 선택·트레이 설정을 함께 초기화하는 `Restore Default`를 추가했습니다.

## 자동 검증

- Visual Studio 2022, CMake, Ninja 및 pinned vcpkg 구성의 Debug/Release 빌드
- Debug/Release `opencapture_core_tests`, `opencapture_audio_tests`
- 단축키 검증·표시와 녹화 설정 직렬화/복원 단위 테스트
- NVENC 및 OpenH264 합성 H.264/AAC MKV mux 검증
- 패키지 manifest, ZIP SHA-256 및 GitHub Release 재다운로드 검증

실제 화면/게임 녹화와 실제 키 입력 UI 수용 테스트는 자동 검증 범위에 포함되지 않습니다.
게임 부하 중 장시간 drop rate·A/V drift, GPU별 인코딩 동작, 실제 Windows 단축키 충돌과
설정 초기화 UX는 수동 수용 기준으로 남습니다.

## 알려진 경계

- 하드웨어 인코딩 가용성은 GPU와 드라이버에 따라 달라집니다.
- 실행 파일은 Authenticode 서명되지 않은 기술 프리뷰입니다.

## 설치

1. `OpenCapture-0.2.2-windows-x64.zip`과 `SHA256SUMS.txt`를 내려받습니다.
2. SHA-256을 확인하고 쓰기 가능한 폴더에 압축을 풉니다.
3. `OpenCapture.exe`를 실행합니다. 별도 설치 프로그램이나 관리자 권한은 필요하지 않습니다.
