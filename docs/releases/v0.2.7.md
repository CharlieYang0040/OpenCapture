# OpenCapture v0.2.7 - Focused UI and Bounded Refresh

OpenCapture v0.2.7은 큰 창에서도 핵심 작업 영역을 읽기 쉽게 유지하고, 녹화 중 UI와
진단 캡처가 불필요한 GPU·CPU 작업을 만들지 않도록 갱신 경로를 정리한 Windows x64
기술 프리뷰입니다.

## 주요 변경

- 메인 콘텐츠 폭을 최대 1200픽셀로 제한하고 넓은 창에서는 가운데 정렬합니다.
- 고급 인코더 선택 컨트롤의 레이블과 콤보 정렬을 일관되게 수정합니다.
- 실제 녹화·스크린샷만 전체 실시간 파이프라인을 실행합니다.
- GPU 변환 smoke는 프레임 처리만 수행하고, 일반 WGC 진단은 캡처 큐만 비워 프레임
  드롭을 막으면서 불필요한 변환·인코더·오디오 점검을 피합니다.
- 녹화 중 UI 입력 반응은 최대 약 30Hz, 상태 갱신은 10Hz로 제한합니다.
- 일반 UI의 hover/툴팁 갱신은 20Hz로 제한하고 다음 갱신 시점까지 Windows 메시지를
  기다려 busy loop를 방지합니다.

## 자동 및 실제 검증

- Visual Studio 2022, CMake, Ninja 및 pinned vcpkg 구성의 Debug/Release 빌드
- Debug/Release `opencapture_core_tests`, `opencapture_audio_tests` 각각 2/2 통과
- 일반 WGC drain, GPU NV12 변환 및 A/V mux smoke 통과
- Computer Use로 Capture/Video 화면과 1200픽셀 제한 레이아웃 확인
- Release 유휴 5초 CPU 표본은 측정된 CPU 시간 0초
- 41.40초 실제 1080p60 H.264 NVENC 녹화에서 소스 2,482프레임, 캡처 드롭 0,
  실시간 드롭 0, 인코더 드롭 0 확인
- 실제 UI에서 녹화 일시정지, 재개, 정지와 MKV 최종 이름 커밋 확인

## 알려진 경계

- CPU 표본은 짧은 단일 PC 측정이며 GPU 사용률이나 게임 FPS, 1% low를 의미하지
  않습니다.
- 실제 게임 부하 비교, 장시간 A/V 드리프트, QSV/AMF와 다른 GPU·드라이버 조합은
  별도 수용 시험이 필요합니다.
- 5ms 캡처 대기를 WGC 프레임 이벤트와 Windows 메시지의 단일 대기로 합치는 더 큰
  변경은 타이밍 회귀 위험 때문에 이번 릴리스에 포함하지 않았습니다.
- 실행 파일은 Authenticode 서명되지 않은 기술 프리뷰입니다.

## 설치

1. `OpenCapture-0.2.7-windows-x64.zip`과 `SHA256SUMS.txt`를 내려받습니다.
2. SHA-256을 확인하고 쓰기 가능한 폴더에 압축을 풉니다.
3. `OpenCapture.exe`를 실행합니다. 별도 설치 프로그램이나 관리자 권한은 필요하지 않습니다.
