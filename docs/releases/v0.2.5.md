# OpenCapture v0.2.5 - Responsive Recording Pipeline and Quality First

OpenCapture v0.2.5는 게임의 렌더링 여유를 보호하는 제한형 녹화 파이프라인, 실제
하드웨어 검증을 거치는 코덱 자동 선택, 통합 녹화 프로필과 품질 우선 프리셋을 추가한
Windows x64 기술 프리뷰입니다.

## 주요 변경

- `게임 성능`, `균형`, `용량 절약`, `품질 우선`, `직접 설정`의 목적 중심 프로필로
  녹화 옵션을 통합했습니다.
- 캡처/UI 스레드와 비디오 인코더를 분리한 4프레임 bounded worker를 추가하고, 적체 시
  오래된 프레임을 버려 게임과 UI가 인코더를 기다리지 않도록 했습니다.
- `용량 절약`의 NVENC 설정에서 temporal AQ와 lookahead를 제거하고 P5를 사용해,
  제한된 비트레이트 안에서 GPU 연산량이 과도하게 커지지 않도록 조정했습니다.
- `품질 우선`은 HEVC, 원본 해상도, 60fps, NVENC P6/HQ, lookahead 8, B-frame 3,
  quarter-resolution multipass와 더 높은 자동 비트레이트를 사용합니다.
- 프로필별 예상 GPU 압력을 표시합니다. 이 표시는 설정을 바탕으로 한 정성적 예측이며
  실제 게임 FPS 측정값은 아닙니다.
- 앱 시작 시 활성 D3D11 GPU에서 인코더를 실제로 열어 본 결과를 캐시하고, Auto가
  AV1 → HEVC → H.264 하드웨어 순서로 선택한 뒤 필요할 때만 소프트웨어로 폴백합니다.
- 등록 여부만 통과한 인코더가 실제 시작 시 실패하면 다음 후보로 계속 진행하며,
  muxer 시작 실패도 동일한 폴백 경로에서 처리합니다.
- Windows Graphics Capture에 요청 FPS 기반 `MinUpdateInterval`을 적용하고 NV12 출력
  텍스처 풀을 늘려 프레임 전달과 인코더 제출의 순간 변동을 흡수합니다.
- 최신 프레임 드롭, worker 큐 깊이·드롭·최대 제출 시간 진단을 추가했습니다.
- MP4 무재인코딩 remux가 성공한 경우에만 원본 MKV를 제거하고, 실패하면 복구 가능한
  MKV를 보존합니다.
- 설정 스키마를 2로 올리고 이전 설정을 안전한 호환값으로 마이그레이션합니다.
- 현재 영상 경로가 SDR BT.709 8-bit이며 HDR/10-bit가 활성화되지 않았음을 UI에
  명시했습니다.

## 자동 및 기능 검증

- Visual Studio 2022, CMake, Ninja 및 pinned vcpkg 구성의 Debug/Release 빌드
- Debug/Release `opencapture_core_tests`, `opencapture_audio_tests` 각각 2/2 통과
- Auto 합성 입력 10초 녹화에서 HEVC 600 영상 패킷 및 정확한 10.000초 타임라인 확인
- 실제 Windows Graphics Capture 품질 우선 경로에서 HEVC 1920x1080 60fps 녹화 확인
- H.264 1920x1080 MP4 remux 성공, 스트림 판독 및 원본 MKV 제거 확인
- 일시정지 타임라인 제거 경로와 정상 파일 확정 확인
- 강제 MP4 변환 실패 시 최종 MP4가 생성되지 않고 판독 가능한 `.part.mkv`가
  보존되는지 확인

## 알려진 경계

- 요청에 따라 실제 게임 FPS, 1% low, GPU 사용률의 프리셋 간 비교 측정은 수행하지
  않았습니다. GPU 압력 표시는 코드 경로와 설정을 바탕으로 한 예측입니다.
- 실제 HEVC/AV1 및 품질 프리셋의 처리 여유는 GPU 세대, 드라이버, 게임 부하, 해상도에
  따라 달라집니다. 앱은 실제 encoder-open 검증과 안전 폴백을 수행하지만 장시간 실기
  검증을 대체하지 않습니다.
- 현재 녹화 경로는 SDR BT.709 8-bit입니다. HDR/10-bit 캡처와 색 메타데이터 전달은
  아직 구현하지 않았습니다.
- Intel QSV, AMD AMF, AV1 지원 GPU, 장시간 A/V drift 및 4K 실기 부하는 이번 자동
  수용 시험에 포함하지 않았습니다.
- 실행 파일은 Authenticode 서명되지 않은 기술 프리뷰입니다.

## 설치

1. `OpenCapture-0.2.5-windows-x64.zip`과 `SHA256SUMS.txt`를 내려받습니다.
2. SHA-256을 확인하고 쓰기 가능한 폴더에 압축을 풉니다.
3. `OpenCapture.exe`를 실행합니다. 별도 설치 프로그램이나 관리자 권한은 필요하지 않습니다.
